# Annulus Specification: Provenance Register

Status: draft 1, 2026-11-10.

## The rule (the owner)

1. **Within one work's line of copies, the oldest witness wins** for the same item: a sign, a name form, an office, a number or a direction.
2. **The rule never crosses between separate works.** Each work is a separate rite (`authority.md` §4), and its readings stand, attributed.
3. **Later material stands where it doesn't clash,** labelled as later, with its source.
4. **Disagreements are recorded,** with attribution. Nothing is sanitised.
5. **Inventions are labelled [O]** (original to Annulus) and never presented as tradition.
6. **A witness's *intended* reading counts.** Where a witness contradicts itself (a misprint), its own internal evidence decides. Example: Arbatel 1575 prints Bethor XXXII but a total of CLXXXXVI, so the edition intends 42.
